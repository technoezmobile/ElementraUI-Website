# ElementraUI Website Launch Guide

This checklist covers the public launch of the ElementraUI website repository. The AI coding skill is maintained separately in [ElementraUI-Skill](https://github.com/technoezmobile/ElementraUI-Skill).

## Before Launch

- [ ] Run `npm install` and `npm run build` from a clean checkout.
- [ ] Run the relevant marketplace and browser verification commands from the root README.
- [ ] Confirm the latest deployment is healthy. The latest checked commit reported a successful Vercel status check.
- [ ] Review the catalogue counts and remove or correct any figures that are no longer accurate.
- [ ] Verify all third-party components, assets, and provenance records retain their required attribution and licensing.
- [ ] Confirm issue reporting, contribution, security, and license documentation are visible and current.
- [ ] If publishing a production URL, add only the verified canonical URL to the repository's About section and README.

## GitHub About Settings

The repository metadata was not changed through this launch guide. Suggested values:

- **Description:** Open-source UI component discovery platform with verified previews, themes, templates, tools, icons, and motion resources.
- **Topics:** `react`, `typescript`, `vite`, `tailwindcss`, `ui-components`, `design-system`, `component-library`, `frontend`, `framer-motion`, `threejs`
- **Website:** Add the verified public deployment URL only after it is available.

## Launch Copy

### Short announcement

ElementraUI is now open source: a developer-first place to discover, preview, and evaluate UI components, themes, templates, mini-apps, icons, and motion resources. Explore the project, run it locally, and contribute improvements: https://github.com/technoezmobile/ElementraUI-Website

### Community post

We are launching ElementraUI, an open-source UI component discovery platform built for practical frontend work. It brings component records, sandboxed previews, themes, templates, runnable tools, icons, and motion resources into one developer-oriented catalogue.

The repository includes local setup instructions, verification commands, documentation, and contribution guidance. The companion AI coding skill remains a separate project for teams that want an agent workflow around evaluating and integrating ElementraUI resources.

Explore or contribute: https://github.com/technoezmobile/ElementraUI-Website

## Launch Day

- [ ] Publish the approved announcement from an official account.
- [ ] Pin the repository or include it in the organization profile.
- [ ] Add the verified production URL and suggested topics in GitHub's About panel.
- [ ] Link the companion [ElementraUI Skill](https://github.com/technoezmobile/ElementraUI-Skill) where appropriate.
- [ ] Monitor issues and pull requests; label and acknowledge actionable feedback.

## After Launch

- [ ] Triage feedback weekly.
- [ ] Keep validation and documentation aligned with catalogue changes.
- [ ] Publish a changelog entry for meaningful releases.
